# Branding

The launcher uses the revised [gold/teal/navy artwork](../assets/branding/aqaqeer-icon-gold-teal-navy-bold.png), packaged as [a transparent RGBA bitmap](../app/src/main/res/drawable-nodpi/aqaqeer_launcher.png). Warm gold lettering, clearer jewel-teal details and a bold deep navy outline are baked into the artwork itself. Normal/round manifest icons reference this same non-adaptive bitmap, without a backing shape, adaptive icon or monochrome layer. The previous runtime outline wrapper is removed.

The retained [gold/teal bitmap](../app/src/main/res/drawable-nodpi/aqaqeer_logo.png) remains packaged as [the shared in-app resource](../app/src/main/res/drawable-nodpi/aqaqeer_logo.png) for toolbar, drawer, onboarding, About and PDF headers. Empty states have their own illustration. [Generation provenance and prompt](../assets/branding/launcher-revision.md).

The splash uses the selected current gold/teal/navy emblem with 17% transparent insets, about a 190 dp bitmap edge. App-controlled startup and exit backgrounds follow the saved local theme/accent palette, including pure black for AMOLED and the crimson neutral backgrounds. DisplayPreferences mirrors only theme/accent launch hints into private SharedPreferences; DataStore stays authoritative, refreshes those hints off-main and supplies the actual palette at exit. With no hint, follow system mode/gold. Android can show a system-themed starting frame before activity code runs, especially on Android 12+; exact OEM behavior is not verified. Light/dark resource fallbacks and matching system-bar icons replace the fixed ink presentation.

The 720 ms exit keeps the logo at the native inset bitmap’s size/center. The internal teal line sets turn once in opposite directions over 640 ms; a 160 ms fade starts at 560 ms. Lettering, gold contours, dots and capsule remain stationary. SplashArtwork decodes the same packaged PNG as the launcher on IO. SplashEmblemView uses measured gold-free masks tied to the 1254 px selected master, clipping both the static base and the rotated source pixels; no artwork pixels are rewritten. Update those masks if the selected master changes.

The exit waits for valid decor dimensions instead of abandoning animation on a zero-size callback. Its decorative layer is an ordinary attached view with standard invalidation; it consumes no input and is removed on completion/cancellation. Disabled system animations skip it; activity destruction cancels the exit. Essential local database readiness still gates native dismissal, without a timer or network wait. Android rendering of this revision and the cause of the user’s previously missing animation remain unverified.

Home uses the pharmacy name and revised emblem inline at the RTL start of a compact toolbar with the authenticated data publication timestamp beneath the name, after the right-side hamburger; bulk selection begins through «تحديد» beside filters or by long-pressing a medication card. The drawer opens from the right at min(window width − 72 dp, 320 dp), with a compact emblem/name header, a direct Home action and collapsible Categories (initially open), admin-tool hub and application groups (initially closed), plus Settings in a fixed footer; Home medication creation uses an admin FAB. Home uses adaptive 160 dp minimum columns scaled by max(1, fontScale) and an adjacent detail pane from 840 dp, smaller 8 dp padding and bounded visible name lines; expanded/detail text stays complete. Onboarding shows the revised emblem and prioritizes joining with a connection file; creation is secondary. About retains emblem, name, version and contact. Android 12+/OEM masks, launcher normalization/contrast and physical system-bar transitions remain unverified; additional hardware/human coverage is excluded from required delivery in the [plan](plan.md); [validation](validation.md) records actual evidence.

Presentation uses Noto Sans Arabic UI weights 400/500/600/700, Noto Naskh Arabic medication headings and Latin sans-serif names. Small labels are at least 12 sp. Scientific names lead; optional commercial names use a secondary Arabic label. Light interactive gold is #7A5A12; light mode uses white cards, near-white backgrounds faintly tinted by the selected accent, subtle container roles, no extra tonal surface tint and accent selection; dark gold is #E8C66D on ink surfaces. These are the default primary colors; the installation-local Settings choice can select ذهبي، أزرق، أخضر، أرجواني or قرمزي, with corresponding light/dark primary and secondary selection roles. Optional hues separate cyan-blue, emerald-green, magenta-pink and cool ruby-crimson with rose-neutral surfaces from default amber gold. The separate «أسود» AMOLED mode makes neutral content surfaces pure black with transparent surface tint, keeping the artwork and semantic badge colors. Artwork and semantic status tones keep their existing colors. Bright gold artwork is decoration, not small text. Status palettes stay independently green/amber/red/neutral with text/icons; expiry shares amber/red. Grouped surfaces retain outlineVariant boundaries; medication cards use the lighter outlineVariant role and a 4 dp status edge with colors independent of badge text. Compact strength wraps beneath the first scientific name; availability stays text-only beside expiry. Major group spacing is 24 dp; action-blocking text and medium labels have a 14 sp floor. Compose status/list transitions follow system animation scaling.

All displayed digits use Western 123, including counts and days. Bidi-isolate Latin/date runs; digit formatting never changes stored values. About intentionally retains its separate app name alongside the emblem. Seeded dosage forms use original shaded VectorDrawable illustrations alongside their labels; custom forms use a neutral Other illustration. Linear gradients, contour highlights and beveled edges provide modest depth without ground shadows. Day/night color resources support light, dark and AMOLED surfaces. Only dosage illustrations preserve intrinsic colors; navigation/action icons retain their normal theme tint.

The capsule has a straight two-piece body, rounded ends and a crosswise seam; the suppository has a rounded tip. Syrup/suspension and cream/ointment/gel have distinct illustrative silhouettes/details. Spray uses a nozzle and visible mist. Containers are representative, while written dosage-form labels remain authoritative. The [saved reference](../assets/reference/dosage-forms/README.md) includes the final-set PNG/SVG and the separate gel-material candidate. The in-app logo source pixels are unchanged; empty states use their separate capsule illustration and the launcher uses the separately revised artwork.

Empty states use a dedicated [native capsule illustration](../app/src/main/res/drawable/empty_state_capsule.xml), drawn at 30% opacity: a diagonal two-piece teal/gold body, navy contour/seam and restrained highlights on a transparent canvas. The [full-opacity preview](../assets/branding/empty-state-capsule-preview.png) is rendered from its vector paths; it is artwork evidence, not an Android screenshot. BrandAssets retains shared sampled logo decodes for emblems; EmptyCapsule now draws this independent vector rather than cropping the logo. The user approved replacing the empty-state capsule while retaining the launcher. The in-app bitmap retains its selected pixels; the launcher uses its own revised PNG. Preference controls include 12 dp accent dots beside labels inside the choice chips, sampled from the actual theme primary hex, and a card-layout sample. The retained PURPLE preference key uses the label أرجواني for its purple/magenta hex palette. Unavailable cards add faint diagonal background stripes while retaining fully opaque readable content. Launch-neutral colors are canonical in presentation_colors.xml and referenced by native styles and Compose. These are source decisions, not physical visual acceptance.

Responsive presentation uses a shared 840 dp list/detail breakpoint and a centered 640 dp detail-content limit. Theme shape tokens preserve 8/12/16/24 dp radii. Arabic titleSmall/titleMedium/titleLarge line heights are 23/26/34 sp and headlineSmall/Medium/Large are 36/42/48 sp; display and body/label styles retain their existing values. Short-window decoration shrinks while touch targets stay at least 48 dp.
