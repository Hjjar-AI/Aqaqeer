# Local demo catalog

The `demoDebug` app is **عقاقير — عرض تجريبي**, package `com.aqaqeer.app.demo.debug`. It opens a local psychiatry sample pharmacy in Reader mode, with a simulated Admin mode available in Settings without creating/joining a real pharmacy, importing a connection, or contacting Telegram. Standard remains **عقاقير**, package `com.aqaqeer.app.debug`, and opens setup until configured. Both can coexist with separate app storage.

The product-label links establish ingredient/strength/form, not suitability for a particular patient. The movement-symptom category does not include a claim for tardive dyskinesia. Propranolol's restlessness grouping is informed by the [published akathisia guideline](https://pmc.ncbi.nlm.nih.gov/articles/PMC6299189/); metformin's metabolic grouping is informed by [WHO guidance](https://www.who.int/docs/default-source/severe-mental-disorders/9789241550383-eng.pdf). These groupings involve clinical judgment, including off-label contexts; no regimen, patient-specific advice or treatment instructions are added to the app.

## Fictional pharmacy state

The pharmacy, Outpatient/Inpatient sections, stock statuses and expiry dates are fictional. Initial dataset revision 1 uses only AVAILABLE, LOW and OUT, with an explicit availability entry for every medication in both sections; it contains no missing pairs. The repeating per-section pattern is AVAILABLE, LOW, OUT, OUT, AVAILABLE, LOW, offset by section, covering different stock combinations across sections. Relative to the seed date in Asia/Damascus, the first medication is expired, the second expires in 21 days, lithium carbonate has no expiry, and the others expire in 12 months. Labels verify real product identities, not these fictional pharmacy values.

Only `app/src/demo` contains this dataset. Standard has no sample pharmacy/medications. The seed retains a random non-authorizing verifier; simulated authorization uses a separate sample PIN initially 1234. Real Telegram connections remain unavailable. Reader mode is read-only and uses normal AVAILABLE/LOW visibility; simulated Admin edits temporary sample data using the shared medication, bulk/status, taxonomy, review and History screens. Demo release is disabled.
