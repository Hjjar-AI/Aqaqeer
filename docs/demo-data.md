These are illustrative catalog groupings, not a treatment algorithm, approved-indication claim for every drug-related symptom, or a statement of interchangeability. The product-label links establish ingredient/strength/form, not suitability for a particular patient. The movement-symptom category does not include a claim for tardive dyskinesia. Propranolol's restlessness grouping is informed by the [published akathisia guideline](https://pmc.ncbi.nlm.nih.gov/articles/PMC6299189/); metformin's metabolic grouping is informed by [WHO guidance](https://www.who.int/docs/default-source/severe-mental-disorders/9789241550383-eng.pdf). These groupings involve clinical judgment, including off-label contexts; no regimen, patient-specific advice or treatment instructions are added to the app.

## Fictional pharmacy state

The pharmacy, editor, Outpatient/Inpatient sections, stock statuses and expiry dates are fictional. All four availability statuses appear; one missing Inpatient pair uses the normal UNKNOWN fallback. Relative to the seed date in Asia/Damascus, the first medication is expired, the second expires in 21 days, lithium carbonate has no expiry, and the others expire in 12 months. Labels verify real product identities, not these fictional pharmacy values.

Only `app/src/demo` contains this dataset. Standard has no sample pharmacy/medications. The demo uses a random non-authorizing verifier, remains read-only, and cannot publish or import real connections. Demo release is disabled.

## Existing installations

Fresh demo initialization and guarded seed-version refresh happen in the same Room transaction as the installation marker. Seed version 3 expands the catalog from eight to 40 entries by replacing the recognized previous demo catalog; it also repairs an empty demo installation. It preserves the installation identity and Keystore/database keys. It refuses an unexpected pharmacy, admin authorization, pending work, history, tombstones, restore activation or confirmed remote publication instead of overwriting them. Standard's refresh hook is inert; no schema version or migration is changed. Newer demo seed versions are preserved on downgrade.

Open the explicitly labeled demo APK; standard setup is intentional until configured. Never uninstall or clear a standard pharmacy to repair demo startup. Startup checks for the earlier eight-record seed and standard-data preservation are [user-reported complete](validation.md#user-reported-completion--2026-11-13). The expanded seed has source/integrity review only; its build and initialization/refresh behavior have not been rerun. Installing an updated demo APK lets the existing guarded refresh apply the new catalog on launch; no uninstall/data clearing is needed.
