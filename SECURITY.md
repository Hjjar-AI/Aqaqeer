# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/Hjjar-AI/Aqaqeer/security/advisories/new) for suspected vulnerabilities. If the form is unavailable, email [hjjarmhmmdali@gmail.com](mailto:hjjarmhmmdali@gmail.com). Do not post sensitive details in a public issue.

Never attach PINs, bot tokens, passwords, connection files/links, private signing keys or pharmacy backups. Describe the affected version, expected/observed behavior and sanitized reproduction steps. No response-time guarantee is offered.

Android 6 preview compatibility relies on the device's operating system and certificate store. Unsupported OS versions may have unpatched security issues. On Android 6–9, background apps can read generated connection passwords copied to the clipboard. Share the file and password through separate channels. [Android clipboard security](https://developer.android.com/privacy-and-security/risks/secure-clipboard-handling)

Only the current development line is maintained. Older builds may not receive fixes. Reader/admin separation uses the trusted-user model documented in the product requirements; it is not cryptographic permission separation.
