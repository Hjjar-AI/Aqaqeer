# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/Hjjar-AI/Aqaqeer/security/advisories/new) for suspected vulnerabilities. If the private reporting form is unavailable, do not post sensitive details in a public issue; ask the maintainer to enable private reporting without disclosing the vulnerability.

Never attach PINs, bot tokens, passwords, connection files/links, private signing keys or pharmacy backups. Describe the affected version, expected/observed behavior and sanitized reproduction steps. No response-time guarantee is offered.

Only the current development line is maintained. Older builds may not receive fixes. Reader/admin separation uses the trusted-user model documented in the product requirements; it is not cryptographic permission separation.
