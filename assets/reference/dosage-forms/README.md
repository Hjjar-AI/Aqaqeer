# Dosage-form artwork reference

[Final PNG](final.png) · [Scalable SVG reference](final.svg)

Saved on 2026-11-16. This retained reference shows the prior shaded illustrations in light, dark and AMOLED colors, including enlarged and 24px samples. The app now uses flat blue-grey artwork based on the same silhouettes. It includes the corrected two-piece capsule, rounded suppository tip, spray nozzle/mist, clear L-shaped inhaler, translucent gel blob and distinct ointment tube, and no shadows beneath the objects.

The final picture includes the selected gel material shape; the application still uses the dispenser pending implementation. The other application sources are the `ic_form_*.xml` VectorDrawables under [drawable resources](../../../app/src/main/res/drawable/), with matching [day](../../../app/src/main/res/values/dosage_colors.xml) and [night](../../../app/src/main/res/values-night/dosage_colors.xml) color roles. The SVG/PNG are derived artwork references, not Android screenshots. Containers are representative illustrations; written dosage-form labels remain authoritative.

## Gel material alternative

[PNG example](gel-material-example.png) · [SVG example](gel-material-example.svg)

A separate candidate shows gel as a low, spread-out translucent blob with no curled peak, container or ground shadow. It is shown on light/dark backgrounds at enlarged, 48px and 24px sizes. This shape is included in the final-set reference above; it has not yet replaced the application’s gel dispenser.
