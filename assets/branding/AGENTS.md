# Branding artwork

Follow the [repository rules](../../AGENTS.md). [Branding](../../docs/branding.md) owns placement and product choices; [provenance](launcher-revision.md) identifies the selected master and generation prompts.

- Inspect the current selected master before editing and carry forward all approved refinements across iterations. Change only the requested elements; preserve the latest lettering, palette, geometry and framing constraints. Distinguish a fixed rotation within artwork from an animated rotation; an artwork edit does not authorize changing splash motion or unrelated in-app/PDF assets.
- Inspect generated output rather than trusting the prompt: verify actual dimensions/aspect ratio, alpha/transparency, margins, lettering and requested detail changes before installation. Report percentage/geometry changes as generation targets or approximations unless measured; do not claim pixel preservation for generated edits.
- For a selected project asset, synchronize the canonical master and its consuming packaged resource, verify byte equality, and retain exact prompts/current provenance. Keep previews distinct from the selected artwork; do not install intermediate outputs with unintended framing or design changes.
- Update current artwork links, dimensions and hashes while retaining dated historical evidence with its original provenance and clear supersession. Remove obsolete availability claims without recreating unused artwork merely to repair links. Follow root evidence-retention rules before deleting sources or intermediates.
