The production Room models define the attribution-free initial version 1 for fresh installations. Existing development databases are unsupported and must be rejected without deletion or conversion.

The checked-in [version-1 export](com.aqaqeer.app.data.AqaqeerDatabase/1.json) is **historical**, generated by KSP during the separately authorized 2026-11-13 preview delivery. It predates the 2026-11-16 removal of editor attribution and does not describe the current production models. Its generated identity hash has not been handwritten or reused as evidence for this baseline.

Regenerating and reviewing the initial version-1 export requires separately authorized compilation/KSP. No compilation or schema-generation command was run for this source batch. Runtime initialization, incompatible-storage rejection and restore acceptance remain unexecuted.
